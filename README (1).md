# MV-AT — Опросник медиа-уязвимости

Streamlit-приложение для проведения опросника MV-AT v1.0 онлайн. После
заполнения 52 пунктов пользователь сразу получает персонализированные
результаты: общий балл (TDH), уровень риска, профиль уязвимости, радар-
диаграмму, детальную интерпретацию по 12 шкалам и скачиваемый отчёт.

## Файлы

- `mv_at_app.py` — основное приложение Streamlit (всё в одном файле)
- `requirements.txt` — зависимости
- `README.md` — этот файл

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run mv_at_app.py
```

После запуска приложение откроется в браузере по адресу
`http://localhost:8501`.

## Деплой по публичной ссылке

Самый простой способ получить ссылку, по которой опросник смогут проходить
любые пользователи в любое время:

### Вариант 1 — Streamlit Community Cloud (рекомендуется, бесплатно)

1. Создайте репозиторий на GitHub (например, `mv-at-questionnaire`) и
   загрузите туда `mv_at_app.py` и `requirements.txt`.
2. Зайдите на https://share.streamlit.io и войдите через GitHub.
3. Нажмите **«New app»**, выберите репозиторий, ветку `main` и файл
   `mv_at_app.py`. Нажмите **«Deploy»**.
4. Через 1–2 минуты вы получите ссылку вида
   `https://<your-name>-mv-at-questionnaire.streamlit.app`. Делитесь
   этой ссылкой — её можно открыть с любого устройства.

### Вариант 2 — Hugging Face Spaces (тоже бесплатно)

1. Создайте новый Space на https://huggingface.co/spaces, выберите
   SDK = **Streamlit**.
2. Загрузите `mv_at_app.py` и `requirements.txt` (можно через web-интерфейс
   или `git push`).
3. Space автоматически соберётся и будет доступен по ссылке вида
   `https://huggingface.co/spaces/<your-name>/mv-at`.

### Вариант 3 — Render.com

1. Загрузите файлы в GitHub.
2. На render.com создайте новый **Web Service** из репозитория.
3. Команда запуска:
   ```bash
   streamlit run mv_at_app.py --server.port $PORT --server.address 0.0.0.0
   ```
4. Получите публичную ссылку. Бесплатный тариф «засыпает» при простое,
   но просыпается за ~30 секунд.

## Что увидит респондент

1. **Главная страница** — описание опросника, ожидаемое время заполнения,
   предупреждение о пилотном статусе.
2. **Опросник** — 52 пункта, сгруппированные в 13 разделов (А + 12),
   с прогресс-баром. Кнопка «Получить результаты» активируется только
   после ответа на все пункты.
3. **Результаты**:
   - 3 ключевые метрики: TDH, MVI, снижение благополучия
   - Цветная карточка уровня риска (низкий / умеренный / повышенный / высокий)
   - Профиль (один из 6 типов) с описанием механизма и 3 рекомендациями
   - Радар-диаграмма по 12 шкалам с цветными зонами риска
   - Альтернативный барчарт
   - Раскрывающиеся блоки по каждой из 13 шкал с цветовой меткой и
     персональной интерпретацией
   - Кнопки скачивания: текстовый отчёт (.txt) и сырые данные (.json)

## Сбор данных для исследования

Текущая версия приложения **не сохраняет ответы на сервере** — каждый
респондент получает свой результат и может скачать его как .txt / .json.
Это сделано осознанно, чтобы избежать вопросов согласия на обработку
данных без явной информированности.

Если для дипломной работы нужно собирать ответы централизованно, два
простых пути:

1. **Попросить респондентов прислать вам .json-файл** (кнопка «Скачать
   сырые данные» уже есть). Самый простой и юридически чистый вариант.
2. **Добавить запись в Google Sheets** — нужно завести сервисный аккаунт
   Google Cloud и в `page_results()` вызывать `gspread`. Могу подготовить
   эту версию по запросу — добавляется ~30 строк кода + чекбокс
   информированного согласия перед стартом.

## Замечания

- Приложение работает на любом устройстве (телефон/планшет/десктоп).
- Все расчёты — на стороне клиента в Streamlit-сессии; данные не
  передаются никуда между сессиями.
- Опросник на русском. Для англоязычной версии нужен перевод текстов
  `ITEMS`, `SUB_INTERPRETATIONS`, `PROFILES`, `SECTION_TITLES`,
  `A_ANCHORS` — структура кода рассчитана на простую локализацию.
